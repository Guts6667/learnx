# Officine Express

Ce dossier contient les artefacts éditoriaux du pilote personnel Officine
Express.

## Inventaire

- `CURRICULUM_BLUEPRINT.md` : finalité, périmètre et architecture ;
- `specs/PEDAGOGY_SPEC_071.json` à `PEDAGOGY_SPEC_077.json` : sept leçons avec
  contenu, preuves, ressources, exercices, évaluations et séquences ;
- `stage-assessments/PEDAGOGY_STAGE_ASSESSMENT_014.json` : évaluation cumulative
  et corrigé éditorial ;
- `../../seed/officine-express-program.json` : bundle compatible avec
  l'importeur Prisma de LearnX.

Le bundle publié comporte une étape, trois modules, sept leçons, sept notions
obligatoires, sept banques de cinq questions et une évaluation finale d'étape.
Les métadonnées de preuve et de revue restent dans les sidecars éditoriaux et
ne sont pas importées dans la base.
