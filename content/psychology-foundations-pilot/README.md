# Psychology Foundations — English pilot

This directory contains the progressive English translation of the canonical
French Psychology Foundations programme.

- Source: `fondamentaux-psychologie`, published version 1.
- Target: `psychology-foundations-pilot`, locale `en`.
- Current scope: two stages, two modules and six lessons.
- Status: editorial review; not ready for publication.
- Required before publication: human linguistic, pedagogical, and cultural/legal reviews through the V3-026 workflow.
- Scientific validation remains independent from translation approval.

The seed bundle is `seed/psychology-foundations-pilot-program.json`. Re-seeding
imports the translated lots as a private draft and must not approve or publish
them.
