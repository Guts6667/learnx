# Archives documentaires

Ces fichiers expliquent les décisions et livraisons V1/V2. Ils sont conservés
pour la traçabilité Git, mais sont remplacés par `BACKLOG_V3.md`, les ADR et les
spécifications actives répertoriées dans `docs/INDEX.md`.

Ne jamais :

- utiliser un ticket archivé comme prochaine instruction ;
- déduire l'état courant du produit depuis un rapport de clôture ancien ;
- charger toutes les archives pour une tâche courante.

Une archive se consulte seulement pour répondre à une question historique
ciblée ou retrouver la justification d'une décision.
